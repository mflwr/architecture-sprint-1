# Задание 1

В качестве фреймворка выбран Module Federation, который позволяет разрабатывать, развертывать и обновлять отдельные
части приложения независимо друг от друга, а также обеспечивает эффективную совместную работу микрофронтендов в едином
интерфейсе.

Разделение функционала предлагается осуществить следующим образом:

- mf-user: микрофронтенд пользователя
- mf-gallery: вывод фотографий, удаление, загрузка, likes
- mf-host: загрузка микрофронтендов и маршрутизация

Потенциальные части для развития и расширения фронтенда:
- авторизацию/аутентификацию можно вынести в отдельный mf-auth, тогда части для auth нужно вынести в него из mf-user
- выделить mf-reactions, если усложнится функционал реакций, или появится микросервис для лайков



Используемые порты:
- mf-host 8080
- mf-user 8081
- mf-gallery 8082


Разделение произведено для следующих элементов:
- компоненты: /components
- API: /utils
- изображения: /images
- стиль и блоки: index.css, /blocks
